# 문제가 많은 게 문제 (TMM) · 난이도 / 문제 구성표 데모

초등학생용 자연수 연산 문제지를 만드는 정적 웹사이트입니다. `index.html`을 브라우저에서 열 수 있으며 GitHub Pages에서도 동작합니다.

## 사용 방법

1. 자릿수 버튼과 사칙연산 버튼을 번갈아 눌러 계산식을 조립합니다.
2. 그 계산식에서 만들 **문제 수**와 난이도 **하 / 중 / 상**을 정합니다. 난이도 버튼 위에 마우스를 올리거나 키보드로 포커스하면 설명이 뜹니다.
3. **유형 추가**를 누릅니다. 원하는 만큼 다른 계산식을 추가합니다(최대 20개 유형, 총 200문제). 구성표에서 수량을 조절하거나 삭제할 수 있습니다.
4. 유형별 묶기 또는 무작위 섞기를 선택합니다.
5. A4 배치(기본 2열 × 10행)를 정하고 **문제지 생성하기**를 누릅니다.
6. 인쇄 또는 PDF 저장을 누릅니다. A4 문제지 안 QR을 스마트폰으로 스캔하면 해당 문제지의 정답이 채워진 페이지가 열립니다.

## 난이도 판정

- 하: 계산 과정에서 받아올림, 받아내림 또는 나눗셈 중간 나머지가 발생하지 않는 식
- 중: 계산 과정에서 1회 발생하는 식
- 상: 계산 과정에서 2회 이상 발생하는 식
- 사칙 혼합 계산에서는 연산 우선순위에 따라 실제 계산한 각 단계의 난이도를 합산합니다.
- 나눗셈은 나누어떨어지는 문제만 생성하고 모든 중간 계산 및 정답에 음수를 허용하지 않습니다.
- 일부 자릿수 조합에선 특정 난이도의 문제를 만들 수 없으므로, 그런 경우 무리하게 생성하지 않고 안내 메시지를 표시합니다.

## 배포

`index.html`, `answer.html`, `styles.css`, `main.js`, `answers.js`, `generator.js`, `qr.js`, `QR-LICENSE.txt`, `THIRD_PARTY_LICENSES.txt`를 GitHub 저장소의 최상위에 올립니다. Pages의 `Deploy from a branch → main → /(root)` 설정은 기존대로 사용하면 됩니다.

QR은 문제지의 계산식 유형, 난이도, 문제 수, 배치, 생성용 시드를 URL에 인코딩해 같은 문제를 재현합니다. 서버 없이 사용할 수 있으나, QR을 읽을 수 있는 사람은 누구나 정답을 확인할 수 있습니다. `file://`로 열면 스마트폰에서 QR 링크에 접근할 수 없으니 GitHub Pages로 배포한 뒤 테스트해 주세요.

응용 사칙연산, 소수, 분수는 아직 개발 예정입니다. QR 라이브러리 라이선스는 함께 제공한 라이선스 파일을 참고해 주세요.
