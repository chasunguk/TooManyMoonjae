# TMM · QR 하단 정렬 및 문제 수 자동 기본값

- A4 문제지 소제목과 이름란의 아래쪽을 QR 코드의 아래쪽과 맞췄습니다. QR은 여전히 문제지 안에 있습니다.
- `추가할 문제 수`의 초기 기본값은 한 페이지의 `열 × 행`입니다. 예: 2열 × 10행 → 20문제.
- 열·행을 변경하면 기본 문제 수도 함께 변경됩니다. 단, 문제 수를 직접 수정한 경우에는 해당 수량을 유지합니다.
- 난이도 설정, 유형 구성표, 인쇄, QR 정답 페이지, 문제 번호 및 정답선 정렬은 유지했습니다.

GitHub Pages 저장소 최상단의 `index.html`과 `answer.html`만 새 파일로 교체하면 됩니다.
