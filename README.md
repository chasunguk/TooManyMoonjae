# 문제가 많은 게 문제 (TMM) — 계산기형 데모

초등학생용 자연수 연산 문제지를 만드는 정적 웹사이트입니다.

## 실행 방법

- `index.html`을 브라우저에서 열어보세요.
- 자릿수 버튼과 연산 버튼으로 식을 조립합니다. 연산자를 여러 개 이어서 사용할 수 있습니다.
- 문제 수는 기본 20개이며, 한 장에 2열 × 10행(20개)으로 출력됩니다.
- `문제 생성`을 누르면 새로운 문제지가 만들어집니다.
- 문제지 상단 오른쪽 QR을 휴대전화로 스캔하면 해당 문제의 정답이 적힌 `answer.html` 페이지가 열립니다.
- QR을 휴대전화로 사용하려면 **사이트를 GitHub Pages에 공개해야 합니다.** 로컬 파일(`file://`)의 QR 링크는 휴대전화에서 접근할 수 없습니다.
- 인쇄/PDF 버튼을 누르면 A4 문제지만 출력됩니다. 정답지는 QR 링크의 페이지에서 출력할 수 있습니다.

## GitHub Pages 업로드

이 폴더의 아래 파일들을 모두 저장소 최상위에 올립니다.

- `index.html`
- `answer.html`
- `styles.css`
- `main.js`
- `answers.js`
- `generator.js`
- `qr.js`
- `QR-LICENSE.txt`
- `THIRD_PARTY_LICENSES.txt`

Pages를 `Deploy from a branch → main → /(root)`로 설정합니다.

## 주의 사항

- 현재는 **기본 사칙연산**만 제공하며, 응용·소수·분수는 추후 개발 예정입니다.
- 음수/소수 중간 결과와 나머지가 생기는 나눗셈 문제는 제외합니다.
- 조건상 생성이 불가능하거나 가능한 서로 다른 문제가 부족하면 메시지가 표시됩니다.
- QR은 서버에 답안을 저장하지 않습니다. 동일한 문제들을 재현하는 간단한 정보가 URL에 들어 있어, 스마트폰에서도 같은 정답지가 생성됩니다.
- QR을 포함한 문제지를 웹에 공개하면 QR을 읽은 누구나 답안을 볼 수 있습니다.
- QR 생성 코드의 라이선스는 `QR-LICENSE.txt` 및 `THIRD_PARTY_LICENSES.txt`에 명시되어 있습니다.
