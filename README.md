# 문제가 많은 게 문제 (TMM) — 심플 데모

사진 속 메모처럼 최대한 단순한 흑백 화면으로 정리한 초등 연산 문제지 생성기입니다.

## 사용법

1. `index.html`을 브라우저에서 열면 됩니다.
2. **나만의 문제**를 눌러 자릿수와 연산 버튼으로 계산식을 만드세요. 연산자 개수 제한은 없습니다.
3. **문제지 설정**에서 문제 수와 출력 열 수를 정하세요.
4. **문제 생성**을 누르면 **문제지 미리보기**가 열립니다.
5. 문제지·정답지를 각각 인쇄하거나 PDF로 저장할 수 있습니다.
6. 좌측 상단 **메뉴**에서 연산 유형을 확인할 수 있습니다. 응용·소수·분수는 추후 개발 예정입니다.

음수 중간 결과와 음수 정답을 만들지 않으며, 나눗셈은 나누어떨어지는 경우만 생성합니다. 조건이 맞지 않는 식은 생성 불가능 안내를 표시합니다. 계산은 방문자 브라우저에서 실행되므로 별도 서버가 필요하지 않습니다.

## GitHub Pages 배포

GitHub 저장소의 최상위에 `index.html`, `favicon.svg`, `.nojekyll`을 업로드하세요. Settings → Pages → Deploy from a branch → `main` / `(root)`를 저장하면 됩니다.
