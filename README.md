# 문제가 많은 게 문제 (TMM)

**Too Many Moonjae** · 선생님이 수업에 사용할 초등 연산 문제지를 만들고 인쇄할 수 있는 무료 웹사이트 데모입니다.

웹사이트: <https://chasunguk.github.io/TooManyMoonjae/>

> 이 저장소는 현재 **기본 사칙연산 데모**입니다. 응용 사칙연산(괄호), 소수, 분수는 추후 개발 예정입니다.

## 주요 기능

- **계산기식 문제 유형 만들기**: `한 자리 수`부터 `네 자리 수`까지의 버튼과 `+`, `−`, `×`, `÷`를 원하는 순서대로 눌러 연산식을 조립합니다. 연산자 개수는 정해진 한도가 없습니다.
- **여러 유형을 한 문제지에 담기**: 예를 들어 `세 자리 수 + 세 자리 수` 10문제와 `세 자리 수 + 두 자리 수` 10문제를 하나로 합칠 수 있습니다. 동일한 유형도 난이도별로 따로 추가할 수 있습니다.
- **난이도 하 / 중 / 상**: 버튼에 마우스를 올리거나 키보드로 포커스를 맞추면 연산별 난이도 기준이 표시됩니다. 자릿수는 그대로 두고 계산 과정의 복잡도를 조절합니다.
- **문제 배치**: 유형별 묶기 또는 무작위 섞기를 선택할 수 있습니다. 유형 개수가 행 수에 정확히 맞으면 열 단위로 정렬합니다.
- **A4 출력**: 한 장의 열 수(1~4)와 행 수(1~15)를 설정하고, 실제 A4 비율의 미리보기를 보면서 출력하거나 PDF로 저장합니다. 기본값은 `2열 × 10행`입니다.
- **페이지별 소제목**: 각 A4 페이지에 실제로 들어가는 문제 유형을 구성표의 계산식·난이도·문항 수로 표시합니다. 긴 수식은 문제 칸 안에서 줄바꿈하고 정답란이 다음 줄로 이동할 수 있습니다. 행·열이 너무 빽빽해 겹침이 예상되면 인쇄를 막고 배치 변경을 안내합니다.
- **QR 정답지**: 문제지 상단의 QR 코드를 휴대전화로 찍으면 해당 문제지와 같은 순서의 문제와 정답을 표시합니다. 휴대전화에서도 원래 문제지의 행·열과 문제 번호 위치를 유지하며, 3열 이상에서는 좌우 스크롤을 지원합니다. 돌아가기 버튼은 표시하지 않습니다.

## 사용 방법

1. 웹사이트의 계산기에서 숫자 자릿수 버튼과 사칙연산 버튼으로 원하는 **문제 유형**을 만듭니다. 첫 화면의 계산식은 비어 있습니다.
2. 오른쪽에서 **추가할 문제 수**와 **난이도**를 정합니다. 추가할 문제 수의 **초기값은 20**입니다. 행·열 설정을 직접 바꾸고 아직 문제 수를 별도로 수정하지 않았다면, 이 값이 `열 × 행`으로 자동 변경됩니다.
3. **+ 유형 추가**를 누릅니다. 계산식 입력칸이 비워지고, 새 유형이 **문제 구성표**에 들어갑니다.
4. 필요한 만큼 다른 유형을 추가합니다. 구성표에서 유형별 문제 수 변경 또는 삭제가 가능합니다.
5. **유형별 묶기**나 **무작위 섞기**를 선택하고 **문제지 생성하기**를 누릅니다.
6. 하단의 A4 **문제지 미리보기**에서 각 페이지의 소제목과 문제 배치를 확인한 뒤 **문제지 인쇄 / PDF**를 이용합니다. 긴 식 때문에 줄이 겹친다는 안내가 나오면 열 또는 행 수를 줄여 주세요. 필요하면 같은 구성으로 다시 생성해 새로운 난수 문제지를 만들 수 있습니다.
7. 학생에게 인쇄물을 나눠주면, 학생은 우측 상단 QR을 통해 **정답 페이지**를 휴대전화로 볼 수 있습니다. 정답 페이지는 문제와 정답만 보여줍니다.

## 난이도 안내

| 난이도 | 덧셈 | 뺄셈 | 곱셈 | 나눗셈 |
| --- | --- | --- | --- | --- |
| 하 | 받아올림 0회 | 받아내림 0회 | 받아올림 0회 | 중간 나머지 0회 |
| 중 | 받아올림 1회 | 받아내림 1회 | 받아올림 1회 | 중간 나머지 1회 |
| 상 | 받아올림 2회 이상 | 받아내림 2회 이상 | 받아올림 여러 번 | 중간 나머지 여러 번 |

난이도는 계산 중 발생하는 연산 과정을 기준으로 분류합니다. 혼합 연산에서는 각 단계에서 발생한 횟수를 합산해 판정합니다. 일부 자릿수 조합은 해당 난이도 문제를 충분히 만들 수 없으며, 그 경우 생성할 수 없다는 메시지가 나옵니다.

**계산 규칙:** 음수(중간 계산 결과 포함)를 허용하지 않으며, 기본 버전의 나눗셈은 각 연산 단계가 나누어떨어져야 합니다. 수식을 평가할 때 곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산합니다.

## GitHub Pages 배포 방법

이 사이트는 별도 백엔드 서버나 데이터베이스 없이 작동합니다.

1. GitHub에서 **Public** 저장소를 만듭니다. 기존 저장소 `TooManyMoonjae`를 사용해도 됩니다.
2. 이 폴더의 **`index.html`, `answer.html`, `README.md`** 파일을 저장소의 **최상위 경로**에 올립니다. ZIP 파일 자체를 업로드하지 마세요.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Deploy from a branch → main → /(root) → Save**를 선택합니다.
5. 배포가 완료되면 `https://<GitHub아이디>.github.io/<저장소이름>/`에 접속합니다. 현재 저장소 기준 주소는 <https://chasunguk.github.io/TooManyMoonjae/> 입니다.

수정 후에는 기존 파일을 같은 이름으로 교체하고 **Commit changes**를 누르면 됩니다. 배포 반영 후 오래된 화면이 보이면 브라우저에서 `Ctrl + Shift + R`로 새로고침해 보세요.

## 파일 구성

```text
TooManyMoonjae/
├── index.html   # 문제 유형 조립, 난이도, A4 문제지, QR 생성
├── answer.html  # QR로 열리는 정답지 (휴대전화에서도 원본 행·열 유지)
└── README.md    # 프로젝트 안내 및 사용 방법
```

HTML 파일 안에 CSS와 JavaScript를 포함한 구조이므로, 배포를 위해 별도의 CSS/JS 파일을 만들 필요는 없습니다. QR 코드 생성용 라이브러리의 저작권 고지는 HTML 파일에 포함되어 있습니다.

## QR 정답지 작동 방식과 유의사항

- QR은 `answer.html`로 연결됩니다. 주소에는 문제 유형, 개수, 문제 순서 재현에 필요한 정보가 포함됩니다. 이를 사용해 같은 문제와 정답을 다시 계산하므로 **서버 저장 공간이 필요하지 않습니다.**
- QR 코드에 개인 정보나 학생 이름을 넣지 않습니다. 하지만 **정답 페이지 주소를 아는 사람은 누구나 정답을 볼 수 있으므로 비밀 정답지 용도로 사용하지 마세요.**
- `index.html`을 PC 파일로 직접 열어 계산기 기능을 시험할 수는 있으나, 휴대전화 QR 연결은 **GitHub Pages 등 웹 호스팅에 업로드한 뒤** 시험해야 합니다.
- 출력 또는 PDF 저장은 웹브라우저의 인쇄 기능을 사용합니다. 인쇄 대화상자에서 A4와 배율을 확인해 주세요.
- 전체 문제지는 **최대 200문제**, 문제 유형은 **최대 20개**까지 구성할 수 있습니다.

## 현재 범위 및 향후 개발

현재: 자연수 사칙연산, 난이도 선택, 여러 문제 유형 구성, A4 출력, QR 정답지, 모바일 정답 확인.

예정: 괄호가 포함된 응용 사칙연산, 소수의 사칙연산, 분수의 사칙연산.
